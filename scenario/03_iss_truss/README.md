## 1. ミッション概要 (Mission Overview)

国際宇宙ステーション（ISS）の巨大な立体トラス構造の中心を貫く主構造ガイドパイプ（全長60m）を、小型点検クローラーがC字型ローラークランプで抱え込みながら巡回し、指定された全4箇所の重要点検ポイント（トラスジョイント部）で電磁メカニカルラッチにより定点ロックして高精度360度レーザー探傷スキャンを実行するミッションです。

真空の宇宙空間では空気抵抗が存在せず、金属パイプを挟持するガイドローラーの転がり抵抗も極めて小さいため、前進する機体は慣性によって等速前進を続けます。減速や停止には **「機体前端のカウンタースラスタ（逆推力噴射）」** が不可欠です。また、3次元空間のカーブ走行では強大な遠心力が発生し、クランプアームの保持限界荷重（$300.0\text{ N}$）を超えるとクランプが外開き破損し、向心力を失った機体はカーブの接線方向へ慣性で飛び出して **宇宙空間へ軌道離脱・漂流（即時失格・ゲームオーバー）** します。

プレイヤーは **「コーナー手前でのキネマティック減速制御」** 、**「カウンタースラスタによる能動急制動と安全把持ラッチ」** 、そして **「ビーム幅と受光感度の物理トレードオフを活かした360度欠陥探索アルゴリズム」** をプログラミングしなければなりません。

## 2. 機体仕様・パイプ軌道物理モデル (Hardware Specs & Guide Pipe Physics)

物理エンジンは 100Hz（$\Delta t = 0.01\text{s}$）周期で機体のパイプ沿面運動、遠心力、真空中制動、および把持ラッチ状態を計算します。

### (1) 機体物理諸元
* **点検機全備質量 ($M$)**: $100.0\text{ kg}$（バッテリー、冷ガススラスタ推進薬、電磁吸着コア、耐放射線シールド含む）
* **機体寸法**: $0.76\text{m} \times 0.36\text{m} \times 0.20\text{m}$（トラス内部の斜交ブレースを安全に通過する超小型扁平カプセル設計）
* **パイプ軌道総延長 ($L$)**: $60.0\text{ m}$
* **クランプ保持限界荷重 ($F_{\text{clamp},\max}$)**: $300.0\text{ N}$（C字クランプアーム外開き破損リミット）
* **点検ジョイント位置**: 全4箇所（$X = 15.0\text{m}, 30.0\text{m}, 45.0\text{m}, 60.0\text{m}$）
* **ジョイント把持許容範囲**: ジョイント位置から $\pm 0.35\text{m}$ かつ 速度 $|v_x| < 0.35\text{ m/s}$

### (2) 遠心力および脱線・破損判定式
1. **カーブ遠心荷重限界（クランプ外開き脱線）**:
   $$F_c = M \frac{v_x^2}{R(x)} \quad (R \approx 5.0\text{ m})$$
   カーブ旋回遠心力が機体側C字クランプ機構の保持限界荷重（$300.0\text{ N}$）を超過した場合（$v_x > 3.87\text{m/s}$）、クランプ保持スプリングが負けてアームが外開き破損し、向心力を失った機体がカーブの接線方向へ慣性で抜け落ちて軌道離脱失格（`DISQUALIFIED (CENTRIFUGAL OVERLOAD)`）となります。
2. **直線部チャタリング脱線（高速脱輪）**:
   パイプを抱え込んで走行していても、速度が過大（$|v_x| > 3.50\text{m/s}$）になると、パイプ継ぎ目の微小段差によってガイドローラーが高周波振動（チャタリング）を起こして浮き上がり脱輪（`DISQUALIFIED (OVER-SPEED CHATTER)`）。
3. **高速クランプによるラッチピン剪断破壊（メカ破損）**:
   ジョイント停止時にカウンタースラスタで十分に減速せず、速度 $|v_x| > 0.40\text{m/s}$ のまま電磁クランプ（`fdir_mode = 1`）を作動させると、ドッキングカラーと係合するラッチピンが激突衝撃で剪断破壊されミッション失格（`DISQUALIFIED (CLAMP PIN SHEAR)`）。

## 3. 360度トラス欠陥探査システム (360° Flaw Inspection Radar)

本ステージでは、4箇所のジョイントのうちランダムに選ばれた3箇所の円周上角度 $\theta \in [30^\circ, 330^\circ]$ に微細クラック（構造欠陥）が潜伏しています（1箇所は健全なダミージョイント）。

### (1) ビーム幅と感度の物理トレードオフ (Energy Dilution Law)
真空の宇宙空間では音波・超音波は伝播しないため、非接触スタンドオフ探査には **光学式レーザースキャナ（LiDAR / Optical Laser Flaw Scanner）** を用います。受光感度ゲインは、ビーム照射幅（チェック幅）に反比例します：
$$\text{Gain} = \frac{15^\circ}{\Delta\theta}$$
* **広角ビーム ($\Delta\theta = 25^\circ$)**: 全周スイープが高速に行えますが、光エネルギー分散により感度が低下（$\text{SNR} \approx 200 \sim 500$）。欠陥候補の発見（粗探索）に最適。
* **狭角ビーム ($\Delta\theta = 8^\circ$)**: 指向性を絞ることでエネルギーが集中し高感度（$\text{SNR} = 1023 \ge 600$）。欠陥確定に必要な $\text{SNR} \ge 600$ を満たす精密ロックに最適。
* **欠陥確定条件**: $\text{SNR} \ge 600$ を $0.15\text{s}$ 以上照射維持（Dwell Time 満了）することで公式審判に記録されます。

### (2) 制御API
```python
# スキャナ角度・ビーム幅制御
hw.set_inspection_scan(angle_deg=theta, beam_width_deg=beam_w, drive_thrust=0.0, fdir_mode=1)
```

## 5. 採点基準 & 公式審判システム (Official Referee SSOT)

全4箇所のジョイントスキャンを完了し、60m地点でアンラッチした際に公式審判（`OfficialReferee`）により採点されます：

$$\text{Final Score} = \text{Joints Score} + \text{Defects Score} + \text{Time Bonus} + \text{Battery Bonus}$$

### (1) 配点内訳
1. **ジョイント把持配点 (全4箇所: 15m, 30m, 45m, 60m)**:
   * 正常把持（誤差 $\le 0.35\text{m}$ かつ 速度 $< 0.35\text{m/s}$）: **各 1,000 pts（最大 4,000 pts）**
2. **微細欠陥検出配点 (ランダム潜伏 3箇所)**:
   * 360度探査による欠陥特定・確定: **1箇所につき +1,500 pts（最大 4,500 pts）**
3. **タイムボーナス**:
   $$\text{Time Bonus} = \max(0, (75.0 - \text{Clear Time}) \times 50.0)$$
4. **バッテリー残量ボーナス**:
   $$\text{Battery Bonus} = \text{Battery}(\%) \times 10.0$$

### (2) フライトランク認定基準
* 🏆 **GRADE S (Master Inspector)**: **8,000 pts 以上 かつ 欠陥全3箇所検出**
* 🥇 **GRADE A (Certified)**: 6,500 pts 以上 かつ 欠陥2箇所以上検出
* 🥈 **GRADE B (Standard)**: 4,500 pts 以上
* 🥉 **GRADE C (Pass)**: 4,500 pts 未満

## 6. パイプ力学と高信頼性制御アーキテクチャ

1. **カーブ区間遠心力限界と事前減速制御**:
   - 2箇所の急カーブ（20-25m, 40-45m）は曲率半径 $R=5.0\text{m}$（曲率 $0.20\text{m}^{-1}$）として計算されます。
   - 遠心荷重 $F_c = M v^2 / R = 20 v^2$ に対し、クランプ許容リミットは $300.0\text{ N}$（脱線限界速度 $\approx 3.87\text{m/s}$）。
   - 推奨旋回速度 $v \approx 1.1 \sim 1.3\text{m/s}$ に事前減速することで、遠心力 $F_c < 35\text{N}$（負荷わずか 11%）の極めて安全なマージンを維持します。
2. **ドッキングカラー・ラッチ機構 (Collar Latch Dynamics)**:
   - 各ジョイント位置には環状のドッキングカラーが設置されており、`fdir_mode = 1` が書き込まれると電磁吸着および機械的ラッチピンがカラーに係合し、スキャン中の機体をガタつきなく定点に剛体ロックします。
3. **60.0m 終端安全エンドストッパー (Terminal Endstop)**:
   - パイプ終端（$X=60.0\text{m}$）には物理的ダンパーが備わっており、万が一のオーバーラン時も機体を安全に受け止めます。
