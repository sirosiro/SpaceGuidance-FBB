# Stage 2: 宇宙テザークライマー (Orbital Tether Climber)

**難易度: Level 2 (初中級) | 物理空間: 1D直線運動 ＋ 弦の弾性波・共振振動力学**

---

## 1. ミッション概要 (Mission Overview)

静止軌道ステーション（GEO）と小惑星採掘基地を結ぶ超長大カーボンナノチューブ・テザーケーブルを昇降機（Climber）が超高速で自律昇降するミッションです。

テザーケーブルは長大なため「弾性を持つ弦」として振る舞います。昇降機の加速・減速時の急激なトルク変動（Jerk）はテザーに縦波・横波の衝撃として伝播し、昇降機の駆動周波数がケーブルの固有振動数（$f_0$）に一致すると**激しい共振現象**を引き起こします。共振が限界振幅を超えるとケーブル断裂事故（即時ゲームオーバー）に至るため、**「ハードウェア・ノッチフィルタ」と「滑らかなS字加減速」** を組み合わせた共振抑制制御が必須となります。

---

## 2. 物理・力学モデル構想 (Physics Model)

### (1) 昇降機・テザー連成振動方程式
昇降機の位置 $x(t)$ とケーブルの弾性変位 $y(z, t)$ は以下の連成系としてモデル化されます：

$$M \ddot{x} + C_{\text{cable}} \dot{x} + K_{\text{cable}} x = F_{\text{drive}}(t) - F_{\text{drag}}$$

$$\frac{\partial^2 y}{\partial t^2} = v_s^2 \frac{\partial^2 y}{\partial z^2} - \gamma \frac{\partial y}{\partial t} + \frac{F_{\text{climber}}(t)}{\rho_{\text{linear}}}$$

* **臨界共振周波数 ($f_0$)**: $f_0 \approx 5.0\text{ Hz}$（テザーの基本固有振動モード）
* **ケーブル許容限界張力**: $T_{\max} = 15,000\text{ N}$（張力変動 $\Delta T$ が許容値を超えると断裂判定）

## 3. ハードウェア (PL) と ソフトウェア (PS) の役割分担構想

| レイヤー | コンポーネント | 役割と責務 |
| :--- | :--- | :--- |
| **PL (FPGA RTL)** | **高速光学マークカウンタ** | テザー表面に刻まれた光学基準マーク（バーコード）をナノ秒でインクリメント計測する高精度ハードウェアエンコーダ |
| | **プログラマブル・ノッチフィルタ** | ケーブル固有共振周波数（$f_0$）近傍のトルク指令成分を急峻にカットする 2次 IIR / CIC デジタルフィルタ回路 |
| | **過大張力安全遮断 (E-STOP)** | 張力センサ値が破断寸前閾値を超えた瞬間に駆動モータを回生ブレーキへ自動フォールバック |
| **PS (Python)** | **S字加減速プロファイル生成** | 加速度の微分（Jerk）を厳格に制限する 7次多項式 / 最小ジャーク曲線の軌道プランニング |
| | **逆位相フィードフォワード制御** | テザーの振動位相を予測し、逆位相のモータトルクを重畳して振動をアクティブ減衰 |

## 4. 攻略チューニングゾーン構想 (Tune Zones Memo)

プレイヤーが編集する `pilot.py` 内のパラメータ候補：

* **🎯 TUNE ZONE 1: S字加減速ジャーク制限 (`max_jerk`)**:
  * 急激な加速立ち上がりを抑え、テザーへの初期衝撃波の励起を防止。
* **⚡ TUNE ZONE 2: ノッチフィルタ中心周波数 & Q値 (`notch_freq`, `notch_q`)**:
  * FPGA レジスタに設定するフィルタ遮断帯域。共振周波数 $f_0$ をピンポイントで相殺。
* **🚀 TUNE ZONE 3: 最高巡航速度 vs 張力安全マージン (`target_velocity`)**:
  * 登坂速度を上げるほどクリアタイムが縮まるが、ケーブル張力マージンが削られるトレードオフ。

## 5. 採点・評価システム構想 (Scoring Memo)

$$\text{Score} = \text{Time Bonus} + \text{Tension Stability Bonus} + \text{Energy Efficiency Bonus}$$

* **タイムボーナス**: 目標時間（例: 45秒）より早く頂上ポートへ到達するほど大幅加算。
* **張力安定性ボーナス**: テザー張力変動（$\text{RMS}(\Delta T)$）が小さいほど加算（完全平滑走行で満点）。
* **回生エネルギー効率**: 減速時に回生ブレーキでバッテリーを回収した割合に応じて加算。
