# Stage 3: ISSトラスレール点検機 (ISS Truss Inspector)

**難易度: Level 3 (中上級) | 物理空間: 3次元立体曲面レール軌道 ＋ 遠心力・把持連成力学**

---

## 1. ミッション概要 (Mission Overview)

国際宇宙ステーション（ISS）の複雑な立体トラス構造の外壁レールを這うように巡回し、指定された複数の高重要度点検ポイント（トラスジョイント部）で電磁グリッパーによりレールを把持・固定して高精度レーザースキャンを実行するミッションです。

3次元空間での急カーブ走行では、速度の2乗に比例する強大な遠心力（$F_c = M v^2 / R$）が発生します。トラスレールの許容把持荷重を超えると機体がレールから弾き飛ばされ、宇宙空間へ脱線・漂流します。また、点検ポイント到着時の減速停止・電磁把持・スキャン・離脱の多段階シーケンスを自律ステートマシン（Behavior Tree）で統括する必要があります。

---

## 2. 物理・力学モデル構想 (Physics Model)

### (1) 3次元曲線軌道と遠心力・反作用トルク
* **レール曲率半径 ($R(s)$)**: 直線部（$R = \infty$）から急峻な直角コーナー（$R = 1.5\text{m}$）まで変化。
* **最大許容ラジアル荷重**: $F_{\text{radial},\max} = 300.0\text{ N}$
* **遠心力計算**:
  $$F_c(s) = M \frac{v(s)^2}{R(s)}$$
  機体速度 $v(s)$ が曲率半径 $R(s)$ に対して過大になると、レール固定爪が破損して脱線事故が発生します。

## 4. 攻略チューニングゾーン構想 (Tune Zones Memo)

* **🎯 TUNE ZONE 1: コーナー曲率減速マージン (`corner_safety_margin`)**:
  * コーナー手前でのブレーキング開始位置と許容最大横G（遠心力リミット）の設定。
* **🧲 TUNE ZONE 2: 電磁グリッパー把持ラッチ時間 (`latch_engage_ms`)**:
  * 点検ポイントでの確実な停止と把持判定の最適化（早すぎると滑り、遅すぎるとタイムロス）。
* **📐 TUNE ZONE 3: 3軸 IMU ドリフト補正フィルタゲイン (`imu_complementary_gain`)**:
  * 3次元旋回時の姿勢推定精度の向上。

## 5. 採点・評価システム構想 (Scoring Memo)

$$\text{Score} = \text{Scan Accuracy} + \text{Structural Load Score} + \text{Time Bonus}$$

* **スキャン完了率・精度**: 全点検ポイントで規定の静止把持時間を満たし、高精度データを取得できたか。
* **トラスレール負荷評価**: 走行中にトラスレールに加えた遠心力のピーク値が低いほど高得点。
* **ミッション完遂時間**: 全ポイントの点検を終えてベースステーションへ帰還するまでのタイム。
